# Blinkit Data Analysis & Excel Dashboard

## Overview

This repository contains a data analysis and visualization project focused on Blinkit's operational and sales data. The goal of this project is to transform raw dataset entries into a dynamic, interactive Excel Dashboard that provides clear business insights, tracks key performance indicators (KPIs), and highlights sales trends.

## Dataset

The data powering this dashboard is located in the root of this repository.
File: Blinkit_Dataset_Dashboard.xlsx

This dataset includes various metrics related to orders, delivery times, customer ratings, and product categories, which are cleaned and processed to feed the dashboard visualizations.

- Interactive Dashboard: A user-friendly interface built entirely in Microsoft Excel.

- KPI Tracking: High-level metrics summarizing total sales, average order value, and delivery performance.

- Data Visualization: Pivot charts, bar graphs, and trend lines to easily digest complex data.

- Filtering & Slicers: Interactive slicers allowing users to filter data by date, category, or region to drill down into specific insights.

## Tools Used
- Microsoft Excel: For data storage, cleaning (Power Query), aggregation (Pivot Tables), and visualization.

## How to Use
- Clone or download this repository to your local machine.
- Ensure you have Microsoft Excel (2016 or newer recommended) installed.
- Open the Blinkit_Dataset_Dashboard.xlsx file.
- Navigate to the "Dashboard" tab (or equivalent main sheet) to interact with the visualizations. Note: If prompted, click "Enable Editing" and "Enable Content" to allow the Pivot Tables and Slicers to function correctly.
